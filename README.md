# RMIT Practical Data Science – Individual Task 1

This repository contains the final PDF submitted for Individual Task 1.

## Project

The assignment examines credit-risk prediction using two publicly available
datasets:

- Home Credit Default Risk
- Lending Club Credit Risk

The datasets were analysed independently using Random Forest and XGBoost.

## Dataset Sources

Home Credit Default Risk:
https://www.kaggle.com/competitions/home-credit-default-risk/overview

Lending Club Credit Risk:
https://www.kaggle.com/datasets/gabrieloliveirasan/lending-club-credit-risk

The original datasets are not included because of their large size and are
available from the public sources above.
